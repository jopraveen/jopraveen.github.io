# What is an Agent Task?

## Overview

An **agent task** refers to a specific assignment or work item that an AI agent (like GitHub Copilot) is asked to complete within a repository. The agent operates autonomously to understand the requirements, make necessary code changes, and ensure the implementation meets the specified goals.

## How Agent Tasks Work

1. **Task Assignment**: A user creates an issue or provides instructions describing what needs to be done
2. **Analysis**: The agent analyzes the repository structure, codebase, and requirements
3. **Planning**: The agent creates a plan of action with specific steps
4. **Implementation**: The agent makes minimal, focused changes to accomplish the task
5. **Testing**: The agent validates changes through linting, building, and testing
6. **Review**: The agent requests code review before finalizing
7. **Completion**: The agent commits and pushes changes to a pull request

## Key Principles

Agent tasks follow these principles:

- **Minimal Changes**: Make the smallest possible changes to achieve the goal
- **Validation**: Always test and verify changes
- **Documentation**: Keep documentation updated
- **Security**: Never introduce vulnerabilities
- **Quality**: Maintain code quality and consistency
